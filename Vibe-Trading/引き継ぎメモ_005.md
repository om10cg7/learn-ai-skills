## 実際に踏んだ失敗と回避策

- **銘柄検索が日本株で使えない**: `search_symbol` は日本語で Yahoo が非対応、Eastmoney は JSON エラー。英語名でも 0 件。回避策は、銘柄コード（`7203.T`）を自分で書くこと。
- **MCP 経由の `backtest` が失敗**: 原因は、インストール先パスの日本語と、子プロセスの `PYTHONUTF8=1` の組み合わせで、curl が証明書ファイルを開けないこと。切り分けの結果は次のとおり。
  - `PYTHONUTF8=1` のみ: 失敗
  - `PYTHONUTF8=0`: 成功
  - `PYTHONUTF8=1` と ASCII パスの証明書を `CURL_CA_BUNDLE` で指定: 成功
  - 回避策は `.mcp.json` の `env` に `CURL_CA_BUNDLE` を追加すること。Claude Code 再起動後、MCP 経由で 2 本とも成功を確認した。
  - 恒久策は、仮想環境を ASCII パスに作り直すこと。これは未実施。
- **`factor_analysis` の 20 日先リターン**: 重なった期間を毎日複利で積むため、グループ資産が数十億倍になる。20 日先は IC だけを見ること。
- **データのぶれ**: 同じ設定で回し直すと数字が少し変わる（戦略 +253.6% から +260.0%）。Yahoo のデータが毎回微妙に違うためと考えているが、未確認。
- **MCP サーバーの初回接続**: 再起動直後に `CONNECT_TIMEOUT` になることがあった。再起動を繰り返すと接続できた。
- **Chrome タブの固着**: 下書きの更新中、タブが `visibilityState=hidden` になり、キー操作が効かなくなった。タブを閉じて開き直し、JavaScript（`Backspace` の keydown を送る）で本文を空にしてから貼り直して解決した。
- **Gemini の MCP が使えない**: `ask-gemini` と `brainstorm` が `agy: found a SQLite transcript ... could not extract a model reply`（agy 1.3.0）で失敗した。見出し画像の案は Gemini を使わず、Claude が書いた。
- **`make_paste_js.py` の文字化けエラー**: 絵文字で `cp932` の `UnicodeEncodeError`。`PYTHONIOENCODING=utf-8` を付けて実行する。

## 実際に踏んだ失敗と、その回避策

- **`graphify path` が「経路なし」になる**
  - 出力: `No directed path found between 'Settings' and 'create_web_app()'. Re-run with --undirected to search ignoring edge direction.`
  - 原因（`explain` の出力から読み取れること）: 辺が「依存する側 → `Settings`」の向きで張られている
  - 回避策: 出力のメッセージは `--undirected` を勧めている。付けて再実行したかは未検証
- **アプリ内ブラウザで `graph.html` が開けなかった**
  - `file:///` の URL への移動が、ファイルにアクセスできないというエラーになった
  - 回避: PowerShell の `Start-Process` で既定のブラウザに開いた
- **SQL ファイル 2 つが解析されなかった**
  - 警告: `tree_sitter_sql` が未導入。警告文は `pip install "graphifyy[sql]"` を勧めている
  - 回避策は実行していない（`uv tool` 環境で通るかは未検証）
  - ほかに、シンボルがゼロだったコードファイルが 6 つあった（`app/region/hiroshima.py`、`kumamoto.py`、`toyama.py`、`tests/golden/hiroshima/config.js`、`web/page.js` など）
- **`graphify install` が、グローバルの `CLAUDE.md` に追記した**
  - 回避策: 入れたあとに、`~/.claude/CLAUDE.md` の末尾を確認する
- **Bash の Python が `.claude.json` を読めなかった**
  - エラー: `UnicodeDecodeError: 'cp932' codec can't decode`
  - 回避: `python -X utf8` で実行した
- **`check_note.py` が見出しの数を警告した（16 個）**
  - 回避: 過去記事の型（H2 が 6 個）に合わせて直した。直したあとは、エラーも警告もなし
- **関係ない失敗: `tradingview-mcp.exe` が起動できない**
  - 原因: PowerShell で直接起動すると「An Application Control policy has blocked this file.」と出た
  - Graphify とは無関係。回避策は実行していない（組織のセキュリティ制御に当たるため、IT 管理者への確認を勧めた）

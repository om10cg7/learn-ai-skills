## 5. 実際に踏んだ失敗と回避策

実際に試して起きたことだけを書く。

| 失敗 | 回避策 |
|---|---|
| Claude in Chrome で、座標クリックがずれる。表示領域（1920 幅）とスクリーンショットの座標系（1568 幅）が違った | ref を使う。座標を使うときは、倍率（約 0.76〜0.82）を掛ける |
| ドメインをまたぐ移動の後に「Security check failed after cross-domain navigation」が出る | `tabs_context_mcp` を呼び直す |
| LINE STORE のページのスクリーンショットが、何度もタイムアウトした | **解決していない**。`get_page_text` でテキストだけ確認した |
| note のエディタで、メニューや「+」ボタンを ref でクリックしても反応しない | JS で `button[aria-label="メニューを開く"]` を操作し、「画像」を選ぶ。画像は `HTMLInputElement.prototype.click` を差し替えて、ファイル入力を取り出し、`file_upload` で渡す |
| note のエディタで Enter を押すと `<br>` が入る | 段落は貼り付けで作る。見出しは、段落 2 個を選択して、`<p>…</p><h2>…</h2><p>…</p>` を貼り付けて置き換える |
| 同じ記事を別のタブで開いたまま保存すると衝突する | 余分なタブを閉じてから保存する |
| note が一時的に「現在メンテナンス中です」になった | 時間を置いて再試行した |
| コンソール出力の日本語が文字化けする | UTF-8 のファイルに書き出して `Read` で読む |
| 「AI の使用」の申告の一文を、本人が「いらない」と言った | 申告は事実に基づく必要があるため、省かず「AIを使用しています」で申請した。理由を本人に説明した |
| `rembg` で背景を透過すると文字が消えるおそれがある | `rembg` は使わず、背景色の判定で透過した |

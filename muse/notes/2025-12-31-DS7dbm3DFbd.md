# 美しいUIのためのプロンプトハック8ステップ（Lovable）

- 日付: 2025-12-31
- 作者: ai agently @aiagently
- カテゴリ: プロンプト
- 元ネタ: https://www.threads.com/@aiagently/post/DS7dbm3DFbd

## 要約

Threads 投稿（本文はカバー画像のみで、ステップとプロンプト例は作者本人の返信チェーンに 1→8 の連番で掲載）。AI ビルダー Lovable で『AIっぽくない』美しい UI を作るための前提指定8ステップ: 1 スペーシングを統一する（8px グリッド。間隔の乱れが『AIっぽさ』の主因）2 モバイルファーストかデスクトップファーストかを最初に決める（両取りをさせると崩れる。例文『We design mobile-first. All layout decisions are optimized for vertical interaction, thumbs, and single column flow.』）3 グローバルルールを先に定義する（例文『Global Design System: Spacing = 8pt grid / Radius = 20px / Typography = Inter xs-sm-base-lg-xl / Layout = flex-first, responsive, no absolute widths / Visual Language = LiquidGlass V2 (bg-white/10–20)』）4 タイプスケールは1つに決めてテーマ内で固定（xs / sm / base / lg / xl。フォントサイズの自由記述は禁止）5 ページ単位でなくコア部品（ボタン／カード／入力／モーダル）から作り、新画面ではそれを参照させる 6 既存パターンを参照させる（例『Use the same layout as CreateNewPortfolio.tsx, swap chart → table.』。デザインシステムの拡張として扱う）7 固定幅は全部 flex に変換（『w-full flex』の考え方。AI ビルダーは固定 px 思考に寄りがち）8 ダーク先行かライト先行かを早期に確定（影・コントラスト・グラデーション・ガラスの値とブランドの感情が決まる）。主張の核は『見た目の指示より先に、間隔・型・部品・参照の前提をプロンプトで固定する』こと。『Lovable プロジェクト100件超のデザイナー』という肩書きは作者の自己申告で裏取りなし。

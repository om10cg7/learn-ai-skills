# Googleのデザイン仕様フォーマット『DESIGN.md』（AI向けブランド定義ファイル）

- カテゴリ: AIツール

## 要約

Threads 投稿（カルーセル4枚＋作者本人の返信3件で内容を確認）。Google Labs が無料公開した、AI コーディングツール向けのデザイン仕様フォーマット『DESIGN.md』の解説。構造は2層で、YAML フロントマターにブランドカラー・タイポグラフィ・余白・角丸・コンポーネント等のデザイントークンを機械可読な正確値で定義し、本文 Markdown に『なぜその色か（例: 信頼感のため）』『いつ使う／使わない』という意図（デザイン根拠）を自然言語で書く。核は、従来の PDF ブランドガイドラインは仕様しか渡せず意図が制作側に伝わらなかったのに対し、DESIGN.md は意図ごと AI に渡せるため『AIっぽさ』から離れたブランド通りの出力が得られる、という主張。公式 CLI（@google/design.md）の lint でトークン参照切れや WCAG コントラストをチェックでき、diff／export（Tailwind・DTCG）／spec もある。Claude Code／Cursor／Copilot 等、Markdown を読めるツールで利用可能。裏取り済み: 実在する仕様で、Google の AI デザインツール Stitch 由来。仕様ドラフトは 2026-04-21 に google-labs-code/design.md リポジトリで Apache 2.0 公開（ステータスは alpha で変更の可能性あり）。注意点として、エージェントが DESIGN.md を自動で読み込むわけではなく、CLAUDE.md／AGENTS.md／ルールファイルから参照させる運用が前提。既存ノート『Design 2025 vs 2026：AI OSの作り方』（DfVlDBRCAyT）でも DESIGN.md は CLAUDE.md と並ぶブランド定義ファイルとして触れられているが、フォーマット自体の解説は本投稿が初収録。作者の『スライド累計1万枚』等の肩書きは自己申告で裏取りなし。

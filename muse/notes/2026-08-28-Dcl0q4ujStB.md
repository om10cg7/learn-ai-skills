## 要約

Threads の動画投稿（出典は作者本人のコメントで『vibeui.online』と明示。サイトを 2026-11-15 に直接確認し、タイトルどおり全92件の掲載を確認）。AI コーディングエージェントにそのまま渡せる、コピペ用 UI プロンプトの無料ライブラリ。各プロンプトはレイアウトパターンの名前＋1行仕様の短い英語テキストで、デザインの細部を自分で言語化しなくても、汎用的でない見た目の UI を生成させる狙い。カテゴリと件数（サイト表記）: Auth Forms 6（分割画面＋ビジュアル／中央カード／マジックリンクのみ／複数ステップウィザード等）、Pricing 8（3段カード／月額・年額トグル／比較表／使用量スライダー等）、Features・Bento 8（3列アイコングリッド／ベントーグリッド／タブ／アコーディオン等）、Hero Sections 8（中央テキスト＋スクリーンショット／動画背景／グラデーションメッシュ／ターミナル風等）、CTA Banners 7、Stats Bars 7、その他 Nav／Testimonials／Footer／FAQ／ダッシュボード系レイアウト（サイドバー＋メイン／カンバン／メトリクスカード＋チャート等）／Blog／Contact／比較表（対競合）／404・Cookie バナー・ローディング状態まで全92件。Lovable プロンプトハック（DS7dbm3DFbd）が『前提を自分で書く』型なのに対し、こちらは『型のカタログからコピペする』型。

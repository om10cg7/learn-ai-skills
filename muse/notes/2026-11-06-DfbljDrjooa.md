## 要約

『15 Things to Install in Claude』と題したカルーセル（全6枚、内容は解析で確認）。Claude Code を拡張する道具を Skills／Plugins／MCP の3種に分けて各5件ずつ挙げる。まず3種の違いから: Skills は単一の仕事向けの指示フォルダ、Plugins はコマンドやツールを1行で入れるバンドル、MCP は GitHub や Notion、データベースなど外部アプリへのコネクタ。Skills 5件は PDF 作成・編集、Word DOCX 起草、Excel XLSX 構築、PowerPoint PPTX 生成、Skill Creator（指定スライド img_index=2 はこの Skills 詳細の枚）。Plugins 5件は Context7（ライブラリ文書の参照）、Playwright（ブラウザテスト）、Code Review（PR レビュー）、Security Guidance（XSS／インジェクション検査）、Frontend Design（UI 出力の改善）。MCP 5件は GitHub、Filesystem、Notion、Slack、PostgreSQL。全15件の導入コマンド付き手順書は『PLUG』コメントで DM 配布。なおキャプションは『42 powerful add-ons を 5 departments に整理』とうたうが、スライド解析で確認できた構成は上記15件で、42件の内訳は投稿内では確認できなかった。

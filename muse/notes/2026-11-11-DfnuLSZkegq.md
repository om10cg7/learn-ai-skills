# 線画アニメーションを作る無料Claudeスキル『line-art-animation』

- 日付: 2026-11-11
- 作者: 오유상 @dhdbtkd
- カテゴリ: Skill集
- 元ネタ: https://www.threads.com/@dhdbtkd/post/DfnuLSZkegq

## 要約

Threads の動画投稿（韓国語。内容は本文＋作者本人の連結返信とコメント、GitHub リポジトリで確認）。Claude に『夜明けのパン屋、トレイを持ったパン職人、窓辺の猫』と文章で頼むだけで、ペンで描いたような線画の場面が動き出す無料（MIT）の Claude スキル『line-art-animation』の紹介。画像ファイルを一切使わず全部を SVG の線で描くため、拡大しても崩れずマウス操作に反応する。動画の例『村』は太陽をドラッグして時刻を変えられ、人・窓・提灯・猫をクリックすると反応する（動画はパン屋の生成結果ではなく制作者の例だと作者本人がコメントで明記）。中身は SKILL.md＋references/ と依存なしの TypeScript ライブラリ lib/（描画プリミティブ ink.ts／歩行ソルバ gait.ts／バネ・振り子・風の motion.ts／時刻パレット daynight.ts）。歩行はキーフレームでなく解法で生成し（接地した足が移動速度ちょうどで滑る、スイングは最小ジャーク軌道）、ヘッドレス Chrome＋ffmpeg で mp4 書き出し、参照動画の歩行周期や足位置を実測して合わせるスクリプトもある。導入は Claude Code なら git clone https://github.com/JDhruv14/line-art-animation ~/.claude/skills/line-art-animation の1行（README と一致を確認）。Web 版でも ZIP を Customize > Skills に上げれば使える（作者コメント。動画書き出しはローカルが楽とのこと）。依頼例3つ（本人の返信より）: 『夜明けのパン屋を線画アニメーションで: トレイを持ったパン職人、オーブンから立つ湯気、窓辺の猫』『この動画の歩き方をそのまま真似するループ部品に変えて』（動画添付）『昼夜の移り変わりを入れて30秒1080p動画で書き出して』。裏取り済み: リポジトリは実在し 2026-11-10 作成、スター762／フォーク125、MIT ライセンス（2026-11-15 確認）。利用料は Pro／Max の利用枠内で追加課金なしという作者の説明（API キー利用時は別）。

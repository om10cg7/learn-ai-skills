## 要約

『Claude Code は使っているが、書くコードを信用できない』という不安への処方箋として、計画→テスト→簡潔さを担保するプラグイン6つを挙げるカルーセル（全8枚、内容は解析で確認）。1 Superpowers（Lead Planner）: 先に計画し、テストを書き、自己チェックする。本人が『まず入れるならこれ』と推す。2 Matt Pocock Skills（Plan Checker）: コーディング前に計画を詰問する。3 ECC（All-in-One Kit）: スキル・メモリ・セキュリティチェックの全部入り。4 Karpathy Skills（Rule Book）: Karpathy のノートに基づく CLAUDE.md 1ファイルのルール集。5 Ponytail（Simplifier）: 最も単純な修正と少ないコードを強制する。6 Agent Skills（Senior Mentor）: エンジニアリングの習慣を手順化したスキル群。各スライドには導入コマンドと貼る場所、および GitHub のスター数（316k／322k／301k／232k／189k／116k、投稿内表記ママ）が載る。これは本人の『Top 30 Claude Code プラグイン』の棚1/5で、全30は『SENIOR』コメントで配布。

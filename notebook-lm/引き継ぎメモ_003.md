## 実際に踏んだ失敗と、その回避策

1. **`nlm login` が「成功」と出るのに使えない**
   - 症状: `Cookies: 1 extracted` で、`nlm notebook list` が `Authentication expired` になる。`--clear --force` で作り直しても同じ。
   - 原因: インストール済みのソース（`notebooklm_tools\utils\cdp.py` の `is_logged_in`）が、ページのホスト名だけでログイン済みと判定している。これは、コードを読んだうえでの推測で、確定していない。
   - 回避: Chrome を `--remote-debugging-port=18800` と専用の `--user-data-dir` で起動し、手動でサインインする。そのあと `nlm login --provider openclaw --cdp-url http://127.0.0.1:18800 --force` を実行する。結果は `Cookies: 54 extracted`、`CSRF Token: Yes`、アカウント名も表示された。
2. **MCP 登録の直後は、そのセッションにツールが読み込まれない**
   - 回避: Claude のデスクトップアプリを再起動する。再起動後は MCP ツールが使えた。
3. **uv が入っていなかった / PATH がすぐ反映されない**
   - 回避: 公式インストーラー（`irm https://astral.sh/uv/install.ps1 | iex`）で入れ、ターミナルを開き直す。
4. **組み込みブラウザで、noteにログインできず、画像も渡せなかった**
   - 組み込みブラウザは、note に未ログインだった。ファイル選択もできない。このパソコン上の簡易サーバー経由でも、noteのページから画像を取れなかった。
   - 回避: ユーザー本人の Chrome（Claude in Chrome）を使う。見出し画像の入力欄は、「画像をアップロード」を押した瞬間に作られる。先に `HTMLInputElement.prototype.click` を差し替えて、ファイル選択画面を開かせずに入力欄だけ取り出し、`file_upload` でファイルを渡す。
5. **note の引用ブロックは1段落しか入らない**
   - 複数段落や箇条書きを入れると、2段落目以降が引用の外にはみ出る。
   - 回避: `<br>` で1段落にまとめ、箇条書きは「・」にする（`md2note_html.py` が処理する）。
6. **座標クリックがずれる / 切り取りダイアログの「保存」ボタンにラベルが無い**
   - 作業中にウィンドウの大きさが変わった。
   - 回避: ボタンは `find` や `read_page` の ref で押す。「保存」は、ダイアログ内でラベルの無いボタンを ref で押した。
7. **保存前に移動しようとすると「変更が保存されていません」の確認が出る**
   - 回避: `force` で消さず、「下書き保存」を押し直す。保存の確認は、別のブラウザで開き直して行う。
8. **Antigravity の画像の保存先は、会話ごとのフォルダ**
   - 保存先は `C:\Users\om10c\.gemini\antigravity\brain\<会話ID>\`。プロジェクトごとではない。
   - 回避: 会話IDを決め打ちにせず、`find_banner.py` で全フォルダを探す。
9. **改行コードの違いで、`article.md` の差分が大きく見えた**
   - 内容の変更は約60行で、残りは改行コードの違い。そのままコミットした。
10. **既にある本文に貼ると、置き換えではなく追記になる**

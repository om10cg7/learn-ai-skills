## 実際に踏んだ失敗と回避策

- パスワードで IMAP に入れない: Outlook.com の IMAP は、パスワード方式が無効。MSAL による OAuth2(XOAUTH2)に切り替えて解決した。
- アプリ登録が「所属する組織のみ」になっていて、個人アカウントでサインインできない: 画面の保存は `requestedAccessTokenVersion is invalid` で失敗する。マニフェストを直接編集して直した。
- サインイン用のブラウザが自動で開かない: デバイスコード方式に変えた。コードを入力する前に Ctrl+C で止めると、そのコードは使えなくなる。もう一度実行して、新しいコードを取り直す。
- XOAUTH2 の区切り文字(`\x01`)が、制御文字としてファイルに埋め込まれた: ツール経由でエスケープが制御文字に変換された。`chr(1)` を使う書き方に直した。文字列を編集するたびに、制御文字が混ざっていないか確かめる。
- コンソールの文字化け: Windows の既定の文字コード(cp932)で、日本語が文字化けする。`PYTHONIOENCODING=utf-8` を付けて回避した。
- Azure ポータルが、URL を変えるだけでは画面を切り替えない: サイドメニューから移動する必要がある。未保存の変更があると、移動できない。
- 最初のスクリプトの説明文に、使い方の行が重複して残っていた: 記事の付録に載せる前に気づいて、スクリプトと記事の両方から取り除いた。
- 説明文やファイル名に、メルマガの発行者名が入っていた: 現在のファイルでは取り除いた。最初のコミットの履歴にも入っていたが、現在は、その履歴自体が到達できない状態になっている。

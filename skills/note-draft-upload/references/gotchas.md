# 落とし穴の記録

実際に起きたこと。原因と回避策を残す。

## ブラウザ

- **組み込みブラウザは、noteにログインしていないことがある。**
  - 回避: ユーザー本人のChrome（Claude in Chrome）を使う。ログイン済みのことが多い。
  - 組み込みブラウザで試すなら、ログインをユーザーに頼み、トップが表示されるのを確認してから進む。
- **組み込みブラウザは、パソコン内のファイルを選べない。** また、このパソコン上の簡易サーバーにも、noteのページからはつながらなかった。見出し画像は、Claude in Chrome の `file_upload` を使う。
- **ブラウザ画面が勝手に閉じている**ことがある。`tabs_context` で確かめ、閉じていたら開き直す。
- **ウィンドウの大きさが、作業中に変わる。** 座標クリックがずれる。ボタンは `find` / `read_page` の ref で押す。
- **スクリーンショットがタイムアウトする**ことがある（画像のアップロード直後）。数秒待ってからやり直す。

## 本文の貼り付け

- **noteの引用ブロックは1段落しか入らない。** 引用に複数段落や箇条書きを入れると、1段落目だけが引用になり、残りが外にはみ出す。変換スクリプトが、引用内を `<br>` で1段落にまとめ、箇条書きを「・」にする。
- 貼り付け後は、見出し・コードブロック・引用の数を、期待値と比べる。数が合えば、構造は崩れていない。
- 全選択してから貼れば、何度でもやり直せる。重複しない。
- タイトルは別の入力欄。本文の貼り付けには含めない。

## 保存

- 「下書き保存」を押しても、保存中の表示が一瞬で消えることがある。**別のブラウザで開き直して、内容を確かめる。**
- 保存前にページを移動しようとすると、「変更が保存されていません」の確認が出る。`force` で消さない。「下書き保存」を押し直す。
- ログイン画面から編集画面に戻るとき、一度トップページに飛ぶことがある。編集URL（`editor.note.com/notes/<id>/edit/`）を直接開き直す。
- 新規の下書きは、タイトルを入力する前に画面を離れると、中身が空のまま残ることがある。

## やってはいけないこと

- 「公開に進む」を押さない。
- ハッシュタグは、公開の画面で入力する。ユーザーに任せる。
- ログインのパスワードを入力しない。

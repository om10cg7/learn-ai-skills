# 見出し画像の保存場所（環境ごとの設定）

ユーザーは、見出し画像を Google の Antigravity（Gemini）で作っている。作成した画像は、パソコンの次の場所に保存される。

## 設定

- 画像フォルダ: `~/.gemini/antigravity/brain/<会話ID>/`
  - Windows の例: `C:\Users\ユーザー名\.gemini\antigravity\brain\<ID>\`
  - ファイル名の例: `suibokuga_notebooklm_mcp_banner_1791080735072.jpg`
  - 末尾の数字は作成時刻（ミリ秒のUNIX時刻）
- 「バーナー」プロジェクトの画像は、上の会話IDのフォルダにまとまっている。

この設定が変わったら、このファイルを書き換える。他の人の環境では、使わない。

## 画像の探し方

1. 記事のタイトルや、ユーザーが言ったキーワード（例: notebooklm）で、ファイル名を検索する。
2. 候補が複数あれば、**更新日時が新しいものを先に**見る。
3. 画像を `Read` で開いて、記事に合うか目で確かめる。タイトル文字の誤字も見る。
4. 作業フォルダに `見出し画像.jpg` としてコピーする（元のファイルは動かさない）。

## 確認すること

- サイズ（幅×高さ）を調べて、2:1でない場合は、切り取りで上下が切れることを伝える。
- `scripts/c2pa_check.py` で来歴を調べる。
  - 「生成AIによる作成」「SynthID」の記録があれば、AI生成画像として扱う。
  - noteにはAI生成画像の表示ルールがある。公開前に、記事の設定で必要な表示を確認するようユーザーに伝える。
  - 具体的なモデル名は、記録に無ければ「不明」と伝える。Antigravityのフォルダにあるだけでは、Geminiが描いたとは断定できない。

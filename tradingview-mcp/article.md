日本株の株価を確認するたびに、証券会社のアプリやサイトを開いて銘柄を打ち直すのは地味に手間です。Claude Code から直接聞ければ、作業の流れを止めずに済みます。

この記事では、MCP サーバー「tradingview-mcp-server」をインストールし、日本株の株価と日経平均を Claude Code から聞けるところまでをまとめます。APIキーは要りませんでした。

## 🤔 なぜ Claude Code で株価を聞きたいか

株の情報番組の文字起こしを NotebookLM にためていて、要約や質問に使っています。

ただ、要約で「この銘柄が注目されている」と読んでも、今の株価がいくらかは、別のサイトで確認する必要があります。Claude Code から「トヨタの株価は？」と聞ければ、情報の整理と数字の確認を同じ画面で済ませられます。

前回は Claude Code から NotebookLM を呼びました。今回はその続きで、株価です。

## 🛠 tradingview-mcp-server とは？

GitHub で公開されている、市場データを MCP で提供するオープンソースのサーバーです。ライセンスは MIT で、ツールは全部で37個あります。

**今回使う、株価を取るツール**
- yahoo_price：Yahoo Finance から取得。指数や ETF も取れる
- stock_prices：TradingView のスキャナーから取得。複数銘柄をまとめて取れる

**そのほか**
- テクニカル分析、バックテスト、先物、ニュースなど。今回は使っていません

2026年10月時点の README に基づきます。

注意点が2つあります。

1つ目は、TradingView 公式のツールではないことです。README にも「TradingView Inc. とは無関係」と書かれています。データの取得元は公開されているエンドポイントなので、規約や利用条件はご自身で確認してください。

2つ目は、README が「投資助言ではない」と明記していることです。この記事の数字も、動作確認のための例として載せています。

## 🚀 導入手順

### 環境

- OS：Windows 11 Pro
- Claude Code：2.1.251
- uv：0.12.23
- Python：3.11.9（uv が使ったもの）
- tradingview-mcp-server：0.8.1

README の前提は Python 3.10〜3.13 で、3.14 は未対応と書かれています。私の PC には 3.14 も入っていますが、uv が 3.11 を選んでくれたので問題ありませんでした。

### 1. uv を入れる

前回の記事で入れたので、今回は省きます。まだの方は、前回の記事の手順で入れてください。

### 2. tradingview-mcp-server を入れる

```powershell
uv tool install tradingview-mcp-server
```

最後に「Installed 1 executable: tradingview-mcp」と出れば成功です。実行ファイルは C:\Users\ユーザー名\.local\bin に入ります。

### 3. Claude Code に MCP を登録する

README の設定例は Claude Desktop 向けの JSON でした。Claude Code では、コマンド1つで登録できます。

```powershell
claude mcp add --scope user tradingview -- "C:\Users\ユーザー名\.local\bin\tradingview-mcp.exe"
```

`--scope user` を付けると、どのフォルダで Claude Code を開いても使えます。確認はいつものコマンドです。

```powershell
claude mcp list
```

次のように出れば登録できています。

```
tradingview: C:\Users\ユーザー名\.local\bin\tradingview-mcp.exe  - ✔ Connected
```

## ⚠️ ハマったところ

### 登録しても、ツールが出てこない

登録した直後のセッションで、tradingview のツールを探しても、見つかりませんでした。前回と同じで、MCP のツールは Claude Code を再起動するまで読み込まれません。

### 別プロセスでは試せなかった

再起動の前に、`claude -p` で別プロセスから試そうとしました。結果は次の通りです。

```
Failed to authenticate: OAuth session expired and could not be refreshed
```

素直に再起動するのが近道でした。

### 日本株のテクニカル分析は使えない

RSI や MACD を返す coin_analysis に、銘柄 7203、取引所 TSE を渡すと、エラーになりました。

```
No data found for 7203 on KUCOIN.
```

取引所に東証を指定したのに、既定の KUCOIN で探しに行っています。README の対応取引所にも、東証は書かれていません。週足から15分足までを見る multi_timeframe_analysis も同じで、全時間足が「No data」になりました。

それなのに、結果の最後には「HOLD/NO TRADE」という推奨文が付いて返ってきます。エラーを見落とすと、分析の結論のように読めてしまうので、注意が必要です。

## 💻 日本株の株価を聞いてみる

### Claude Code を再起動する

MCP を登録しただけでは、ツールは読み込まれません。Claude Code を再起動すると、mcp__tradingview__ で始まる37個のツールが呼べるようになっていました。数えて、README の数字と一致しました。

結果は、再起動後の Claude Code から実際にツールを呼んで得たものです。取得したのは2026年10月4日（日曜）なので、値は直近の取引日の終値とみられます。

指示は、ツールの説明文を知らない別のエージェント（Claude Code のサブエージェント）に渡して、どのツールが選ばれるかを見ました。

### 1銘柄の株価を聞く

指示は次の通りです。

> トヨタ自動車の今の株価と前日比、52週の高値・安値を教えて

yahoo_price が `7203.T` で呼ばれ、次のように返ってきました。

- 現在値：2,856.5 円
- 前日終値：2,925 円
- 前日比：-68.5 円（-2.34%）
- 52週の高値：4,000 円
- 52週の安値：2,686 円

日本株は、証券コードの後ろに .T を付けた形で渡されます。

### 日経平均を聞く

> 日経平均はいくら？

yahoo_price が `^N225` で呼ばれ、68,309.46 円、前日比 -647.26 円（-0.94%）と返りました。52週の高値は 72,831.73 円、安値は 46,544.05 円です。

### 複数の銘柄を一覧で聞く

> トヨタ、ソニー、三菱UFJ、ソフトバンクグループの株価を一覧で教えて

yahoo_price が、4銘柄分、4回並べて呼ばれました。結果は次の通りです。

- トヨタ自動車（7203）：2,856.5 円（-68.5 円、-2.34%）
- ソニーグループ（6758）：3,753 円（-34 円、-0.90%）
- 三菱UFJフィナンシャル・グループ（8306）：3,544 円（-42 円、-1.17%）
- ソフトバンクグループ（9984）：6,310 円（-391 円、-5.83%）

4銘柄とも前日比はマイナスで、ソフトバンクグループの下げが最も大きくなっています。

### 1回でまとめて取る

銘柄が増えるなら、stock_prices のほうが向いています。取引所を前に付けた形で書くと、こちらが呼ばれました。

> TSE:7203、TSE:9984、TSE:8306、TSE:6758 の現在値と前日比を教えて

4銘柄が、1回の呼び出しで返ってきました。README によると、最大2,000銘柄まで1回で渡せます。

10銘柄を渡して、ツールを直接呼んでも試しました。返ってきたのは次の通りです。

- ソフトバンクグループ（9984）：6,310 円（-5.83%）
- 東京エレクトロン（8035）：12,100 円（-3.82%）
- 三菱UFJフィナンシャル・グループ（8306）：3,544 円（-1.17%）
- トヨタ自動車（7203）：2,856.5 円（-2.34%）
- ファーストリテイリング（9983）：71,770 円（-1.35%）
- リクルートホールディングス（6098）：16,685 円（-0.42%）
- ソニーグループ（6758）：3,753 円（-0.90%）
- キーエンス（6861）：80,270 円（-1.15%）
- 信越化学工業（4063）：6,030 円（+0.05%）
- NTT（9432）：169.9 円（-0.23%）

銘柄名は、ツールが返した英語名から読み取っています。

### 2つのツールの違い

どちらも東証の株価が取れますが、返ってくる項目が違います。

- yahoo_price：現在値、前日終値、前日比（円と%）、52週の高値・安値
- stock_prices：現在値、始値、高値、安値、前日比（%）、銘柄名

前日比を円で知りたいときや、52週の高値・安値が欲しいときは yahoo_price です。多くの銘柄をまとめて見たいときは stock_prices です。トヨタの現在値は、どちらでも 2,856.5 円で一致しました。

### 使ってみて気をつけたいこと

- 銘柄の書き方は、ツールごとに決まっています。yahoo_price は 7203.T の形で、7203 だけだと「404 Not Found」が返ります。stock_prices は TSE:7203 の形で、7203 だけだとエラーになります
- stock_prices は、1つでも書き方が違うと、全体がエラーになります。存在しない銘柄（TSE:9999999）を混ぜた場合は、エラーにならず、not_found に入ります
- stock_prices の結果は、指定した順番では返ってきません。10銘柄の結果も、先頭はソフトバンクグループで、指定した順とは別でした。銘柄名やコードで突き合わせる必要があります
- yahoo_price の market_state は、空で返ってきました。取引中の値か終値かは、結果だけでは判断できません。今回は日曜に取ったので終値のはずですが、平日の場中の見え方は確認していません
- ETF の 1306（NEXT FUNDS TOPIX ETF）は、現在値が 430.2 円なのに、52週の安値が 36.74 円と返りました。分割の影響を受けた値とみられますが、確認はできていません

## 📝 まとめ

- インストールは uv で1コマンド。Claude Code への登録も claude mcp add の1コマンド
- APIキーは不要。登録後は Claude Code を再起動すると、37個のツールが見える
- 「トヨタの株価は？」「日経平均はいくら？」と聞くと、yahoo_price が選ばれた。銘柄は 7203.T の形
- 多くの銘柄をまとめて見たいときは stock_prices。銘柄は TSE:7203 の形で、1回で10銘柄を取れた
- 日本株のテクニカル分析は使えず、エラーなのに「推奨」が返ってくる。結果は、エラーの有無まで見る

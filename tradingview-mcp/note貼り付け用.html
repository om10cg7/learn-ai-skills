3. ハッシュタグ

#ClaudeCode #MCP #日本株 #株価

日本株の株価を確認するたびに、証券会社のアプリやサイトを開いて、銘柄を打ち直すのは地味に手間です。Claude Code に「トヨタの株価は？」と聞くだけで済めば、作業の流れを止めずに済みます。

この記事では、MCP サーバー「tradingview-mcp-server」をインストールして Claude Code に登録し、日本株の株価と日経平均を聞けるところまでをまとめます。APIキーは要りませんでした。

🤔 なぜ Claude Code で株価を聞きたいか

株の情報番組の文字起こしを NotebookLM にためていて、それを Claude Code から呼ぶところまでは前回やりました。

https://note.com/om10cg72/n/nefc00b8250ae

次は数字の側です。要約で「この銘柄が注目されている」と読んでも、今の株価がいくらかは、別のサイトで確認する必要があります。ここも Claude Code から聞けるようになれば、情報の整理と数字の確認を同じ画面で済ませられます。

🛠 tradingview-mcp-server とは？

GitHub の atilaahmettaner/tradingview-mcp で公開されている、市場データを MCP で提供するオープンソースのサーバーです。ライセンスは MIT です。

ツールは全部で37個あり、テクニカル分析、バックテスト、先物、ニュースなども含まれます。今回は、その中で日本株の株価を取る2つに絞りました。

  • yahoo_price：Yahoo Finance から取得
  • stock_prices：TradingView のスキャナーから取得

日本株のテクニカル分析（RSI など）も試しましたが、取引所に東証を指定しても別の取引所で探しに行き、使えませんでした。株価の取得は問題なく動きます。

注意点が2つあります。

1つ目は、TradingView 公式のツールではないことです。README にも「TradingView Inc. とは無関係」と書かれています。データの取得元は公開されているエンドポイントなので、規約や利用条件はご自身で確認してください。

2つ目は、README が「投資助言ではない」と明記していることです。この記事の数字も、動作確認のための例として載せています。

🚀 導入手順

環境

  • OS：Windows 11 Pro
  • Claude Code：2.1.251
  • uv：0.12.23
  • Python：3.11.9（uv が使ったもの）
  • tradingview-mcp-server：0.8.1

README の前提は Python 3.10〜3.13 で、3.14 は未対応と書かれています。私の PC には 3.14 も入っていますが、uv が 3.11 を選んでくれたので問題ありませんでした。

1. uv を入れる

前回の記事で入れたので、今回は省きます。まだの方は、前回の記事の手順で入れてください。

2. tradingview-mcp-server を入れる

uv tool install tradingview-mcp-server

最後に「Installed 1 executable: tradingview-mcp」と出れば成功です。実行ファイルは C:\Users\ユーザー名\.local\bin に入ります。

3. Claude Code に MCP を登録する

README の設定例は Claude Desktop 向けの JSON でした。Claude Code では、コマンド1つで登録できます。

claude mcp add --scope user tradingview -- "C:\Users\ユーザー名\.local\bin\tradingview-mcp.exe"

--scope user を付けると、どのフォルダで Claude Code を開いても使えます。確認はいつものコマンドです。

claude mcp list

次のように出れば登録できています。

tradingview: C:\Users\ユーザー名\.local\bin\tradingview-mcp.exe  - ✔ Connected

なお、前回と同じく、ツールは Claude Code を再起動するまで読み込まれません。再起動すると、mcp__tradingview__ で始まる37個のツールが見えました。

💻 日本株の株価を聞いてみる

結果は、再起動後の Claude Code から実際にツールを呼んで得たものです。取得したのは2026年10月4日（日曜）なので、値は直近の取引日の終値とみられます。

指示は、ツールの説明文を知らない別のエージェント（Claude Code のサブエージェント）に、指示文だけを渡して試しました。どのツールを呼ぶかは、エージェントに任せています。

2つのツールの違い

どちらも東証の株価が取れますが、返ってくる項目が違います。

  • yahoo_price：現在値、前日終値、前日比（円）、前日比（%）、52週の高値・安値。指数（^N225）やETFも取れる
  • stock_prices：現在値、始値、高値、安値、前日比（%）、銘柄名。複数銘柄を1回で取れる

前日比を円で知りたいときや、52週の高値・安値が欲しいときは yahoo_price です。多くの銘柄をまとめて見たいときは stock_prices です。

トヨタの現在値は、どちらでも 2,856.5 円で一致しました。

⚠️ ハマったところ

銘柄の書き方を間違えるとエラーになる

銘柄の書き方は、ツールごとに決まっています。

  • yahoo_price：7203.T の形。7203 だけだと、Yahoo Finance から「404 Not Found」が返る
  • stock_prices：TSE:7203 の形。7203 だけだと、「EXCHANGE:SYMBOL の形で」というエラーになる

stock_prices は、1つでも書き方が違うと、全体がエラーになります。正しい銘柄が混ざっていても、1件も返ってきません。

存在しない銘柄（TSE:9999999）を混ぜた場合は、エラーにならず、返却されなかった銘柄が not_found に入ります。

並び順が、指定した順ではない

stock_prices の結果は、指定した順番では返ってきません。10銘柄を渡した結果は、先頭がソフトバンクグループ、次が東京エレクトロンで、指定した順とは別でした。銘柄名やコードで突き合わせる必要があります。

取引中かどうかが分からない

yahoo_price の結果には market_state という項目がありますが、空で返ってきました。値が取引中のものか、終値なのかは、結果だけでは判断できません。今回は日曜に取ったので終値のはずですが、平日の場中にどう見えるかは確認していません。

ETFの52週安値が極端だった

ETF の 1306（NEXT FUNDS TOPIX ETF）を yahoo_price で取ると、現在値は 430.2 円なのに、52週の安値が 36.74 円と返りました。

現在値と離れすぎているので、分割の影響を受けた値とみられますが、確認はできていません。ETF の52週の値は、そのまま信じないほうがよさそうです。

再起動の代わりに別プロセスで試すのは無理だった

再起動の前に、claude -p で別プロセスから試そうとしましたが、「OAuth session expired」で認証エラーになりました。素直に再起動するのが近道でした。

📝 まとめ

  • インストールは uv で1コマンド。Claude Code への登録も claude mcp add の1コマンド
  • APIキーは不要。登録後は Claude Code を再起動すると、37個のツールが見える
  • 「トヨタの株価は？」「日経平均はいくら？」と聞くと、yahoo_price が選ばれた。銘柄は 7203.T の形
  • 多くの銘柄をまとめて見たいときは stock_prices。銘柄は TSE:7203 の形で、1回で10銘柄を取れた
  • 書き方を間違えるとエラーになり、結果の並び順も指定順ではない。市場が開いているかは、結果から判断できない

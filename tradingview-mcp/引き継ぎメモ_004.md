## 動作確認で分かったこと（Claude Code から実際にツールを呼んだ結果）

- yahoo_price（Yahoo Finance）: 日本株は `7203.T` の形。日経平均は `^N225`。`7203` だけだと 404。
- stock_prices（TradingView スキャナー）: `TSE:7203` の形。取引所なしだと、全体がエラーになる。存在しない銘柄は not_found に入る。10銘柄を1回で取得できた。結果の並び順は、指定順ではない。
- トヨタ（7203）は、2つのツールで 2,856.5 円で一致した。
- 自然な日本語の指示を、ツールの説明文を知らないサブエージェントに渡して試した。選ばれたのは次の通り。
  - 株価・52週高値安値 → yahoo_price（`7203.T`）
  - 複数銘柄の一覧 → yahoo_price を銘柄の数だけ呼ぶ
  - 日経平均 → yahoo_price（`^N225`）
  - `TSE:7203` 形式で書いた指示 → stock_prices
- 日本株のテクニカル分析は使えない。
  - coin_analysis（7203、TSE）は、既定の KUCOIN で探して SYMBOL_NOT_FOUND になる。
  - multi_timeframe_analysis は、全時間足が「No data」なのに、「HOLD/NO TRADE」という推奨文が付く。
  - combined_analysis は、NASDAQ で探してエラーになるのに、「confidence: HIGH」と出る。
- ニュース系（market_sentiment、financial_news）は、キーなしだと 0 件で「MARKETAUX_API_TOKEN not configured」。
- compare_strategies（トヨタ、1y）は、1位が取引0回の戦略（rsi_pullback）になる。ただ持ち続けた場合は +1.84%。
- stock_screener（japan）は、時価総額順だと TSE 以外（NAG）の行も混ざる。NAG が何の取引所かは未検証。
- ETF 1306 の yahoo_price は、現在値 430.2 円に対し、52週安値が 36.74 円と返った。理由は未検証。

## 実際に踏んだ失敗と、その回避策

- 既に本文がある下書きに `paste.js` を実行すると、置き換えではなく追記になり、見出しが倍になった。
  - 回避: 本文エディタを ref でクリックし、キー操作で `ctrl+a`、`Delete` を送って空にしてから貼る。JavaScript の `execCommand('delete')` だけでは消えない。
- 前回記事の URL を、参考にした別記事の URL と取り違えた。
  - 回避: 記事一覧 API（`https://note.com/api/v2/creators/om10cg72/contents?kind=note&page=1&per_page=5`）で、タイトルと URL を突き合わせる。
- `claude -p` で別プロセスから MCP を試すと、「OAuth session expired」で認証エラーになった。
  - 回避: Claude Code を再起動する。
- `make_paste_js.py` を `>` でリダイレクトすると、Windows の cp932 で絵文字の出力に失敗した。
  - 回避: `PYTHONIOENCODING=utf-8` を付けて実行する。
- 記事の中の「サブエージェントに指示だけを渡して、ツールが選ばれるか見る」方法は、自分（メインのセッション）が説明文を読んでしまっているため、自分では確認にならない。
  - 回避: 説明文を知らない別のエージェントに渡す。
